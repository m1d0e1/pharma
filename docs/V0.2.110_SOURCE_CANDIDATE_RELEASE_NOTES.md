# PHARMA v0.2.110 — source candidate (not an approved Windows production release)

This branch makes v0.2.110 application source, native SQLx migrations,
regression tests and relevant non-sensitive operator documentation available
for GitHub review. It does **not** install an executable on the existing
pharmacy, authorize historical owner enrollment, or certify opening balances.

## Included

- TypeScript/Tauri/Rust v0.2.110 changes and native SQLx migrations through
  version 069, using canonical tenant primary_pharmacy.
- One pharmacy-wide shared drawer, with individual transaction attribution
  and no implicit drawer closure when an employee logs out.
- Manual signed offline licensing for newly enrolled commercial pharmacies.
- Protected original-history/SQLx69 QA and recovery source tools and tests.
- Read-only source-bound import authorization and explicit independently
  witnessed legacy financial opening-balance policy.
- Fail-closed historical startup: a device license cannot prove original-data
  ownership or authorize historical financial cutover.

## Not an approved commercial installer

- Actual customer historical SQLite databases, protected financial review
  indices, commercial signing secrets and executable bundles are excluded.

**Do not install this candidate or detached QA SQLite history directly over
a pharmacy system.** An official v0.2.110 release tag and signed installer
require independent release and original-history authorization.
